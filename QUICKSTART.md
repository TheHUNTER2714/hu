# ⚡ Quick Start Guide

## 🚀 Get Started in 3 Steps

### Step 1: Open the Portfolio
```bash
# Simply open index.html in your browser
# Or use a local server:

# Python
python -m http.server 8000

# Node.js
npx http-server
```

### Step 2: Explore
- Scroll to navigate through scenes
- Hover over cards for animations
- Click navigation icons for quick jumps
- Press "P" for a surprise!

### Step 3: Customize & Deploy
- Edit content in `index.html`
- Change colors in `css/style.css`
- Deploy to GitHub Pages, Netlify, or Vercel

## 🎨 Customization Quick Reference

### Change Colors
In `css/style.css` (line 18-25):
```css
:root {
    --color-primary: #ff6b9d;     /* Pink - Main color */
    --color-accent: #ffa801;       /* Orange - Accent */
    --color-purple: #8b5cf6;       /* Purple - Highlights */
}
```

### Update Contact Form
In `index.html` (line ~548):
```html
<form action="https://formspree.io/f/YOUR_ID" method="POST">
```
Get your ID at: https://formspree.io/

## 🐛 Quick Troubleshooting

### 3D Scene Not Showing
- **Issue:** Browser doesn't support WebGL
- **Fix:** Use latest Chrome/Firefox

### Form Not Submitting
- **Issue:** Wrong Formspree ID
- **Fix:** Check form action URL

### Slow Performance
- **Issue:** Too many browser tabs
- **Fix:** Close unused tabs, test in private window

### Mobile Navigation Missing
- **Issue:** Screen too wide
- **Fix:** Resize to < 768px width
