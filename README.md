## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for CDN resources)

### Installation

1. **Clone or download the repository**
```bash
git clone https://github.com/yourusername/portfolio.git
```

2. **Open the project**
```bash
cd portfolio
```

3. **Launch the website**
   - Simply open `index.html` in your browser
   - Or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server
```

4. **Access the portfolio**
   - Navigate to `http://localhost:8000` in your browser

## 🎨 Customization

### Color Scheme
The portfolio uses a sunset-inspired color palette. Modify colors in `css/style.css`:

```css
:root {
    --color-primary: #ff6b9d;      /* Pink */
    --color-secondary: #c44569;    /* Deep pink */
    --color-accent: #ffa801;       /* Orange */
    --color-sky: #4facfe;          /* Sky blue */
    --color-purple: #8b5cf6;       /* Purple */
}
```

### Content Updates
Edit personal information, projects, and achievements in `index.html`.

### 3D Scene Customization
Modify scene objects and animations in `js/main.js`:
- `createCityScene()` - City landscape
- `createSkyScene()` - Cloud particles
- `createRoomScene()` - Interior room

## ⚡ Performance Optimization

- **Lazy Loading** - Resources load as needed
- **Throttled Scroll Events** - Optimized scroll performance
- **Efficient Rendering** - RequestAnimationFrame for smooth 60fps
- **Particle Limit** - Optimized particle count for performance
- **Low-Poly Models** - Lightweight 3D geometry
- **Texture Optimization** - Minimal texture usage
