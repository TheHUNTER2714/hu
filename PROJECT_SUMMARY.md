## 🚀 How to Use

### Quick Start
1. Open `index.html` in a modern web browser
2. Scroll to explore the 3D journey
3. Click navigation icons to jump to sections
4. Hover over cards for interactions
5. Fill out contact form to send messages
6. Press "P" for a fun surprise!

### Local Server (Recommended)
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server
```

Then visit: `http://localhost:8000`
